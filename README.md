# LifeLog

## 概要

LifeLogは、日々の出来事や思い出を時系列で記録・管理できるWebアプリケーションです。
イベントごとにタイトル・説明・日付・場所・感情・背景色・お気に入りなどを登録でき、検索やソート機能によって過去の記録を素早く振り返ることができます。
JavaScriptによるデータ管理やUI設計を意識して制作し、コードの保守性・可読性を重視して開発しました。

## 工夫した点

### ファイル構成の整理

JavaScriptを機能ごとに分割し、役割を明確にしました。

```
js/
├── data/
│   └── dataManager.js
├── ui/
│   ├── card.js
│   ├── line.js
│   ├── modal.js
│   ├── search.js
│   ├── timeline.js
│   └── toast.js
├── utils/
│   └── utils.js
├── views/
│   └── cardView.js
├── add.js
└── app.js
```

---

### データ管理の一元化

データの取得・保存・更新・削除を `DataManager` に集約することで、画面側のコードをシンプルに保ち、保守しやすい設計を意識しました。

---

### UIの改善

検索条件をチップ形式で表示し、個別に削除できるようにすることで、検索条件を視覚的に確認・編集しやすくしました。

また、画面サイズに応じて年ジャンプ機能の表示方法を切り替え、PC・スマートフォンの両方で操作しやすいUIを目指しました。

---

### コードの可読性

各ファイルに処理ごとのコメントを付け、関数単位で役割を明確にしました。

また、処理を関数化することで重複コードを減らし、拡張しやすい構成を意識しています。
